## Discord 狀態核對

既有未提交工作已按路由身分區分選片與明確詳情；海報 hover／焦點不是片名輸入。真正播放的 snapshot 優先於瀏覽，暫停顯示「已暫停」且移除進度倒數，停止後回目前瀏覽路由。Discord 將片名放在 `details`，行為放在 `state`（例如「正在瀏覽作品」＋片名），並保留緩衝與音訊狀態。

主分享、片名與封面同意皆維持既有預設關閉與每帳號範圍；登出、隱私、鎖定及受阻路由會撤回。遲到的詳情／封面查詢受路由、帳號與 generation 約束，不應復活上一部片名。此輪沿用狀態機，只補上「播放→暫停→回媒體庫→退出播放」的合成本機回歸；所有 Discord client／metadata lookup 都是測試替身，不對外廣播。

測試結果由本輪總驗證報告提供；本文件不把程式碼閱讀等同裝置或 Discord 外部顯示驗收。

原生隔離 probe 已實測合成媒體庫／詳情與真正播放控制、選單、自動捲動及返回焦點；這不等於全 App 真資料走查。長片名與 1.8 倍文字另有實際選單 widget 回歸，其他頁面的全面文字縮放、空白／錯誤與無障礙驗收仍留下一批。
