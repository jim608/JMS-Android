# Discord 播放狀態

JMS 的 Windows 與 Linux 版可將播放／暫停狀態顯示在同一台電腦上已登入的 Discord 桌面版。此功能預設關閉，並依目前 JMS 帳號保存選擇。其他平台目前不提供此設定。

在設定頁開啟「在 Discord 顯示播放狀態」前，JMS 會先取得同意。Discord 個人檔案及朋友可能看見您正在使用 JMS，以及播放／暫停狀態；顯示範圍也受 Discord 的活動隱私設定影響。影片名稱預設不分享，需另外開啟「分享影片名稱」並再次確認。您可以隨時關閉任一分享選項。

停止播放、登出或進入隱身模式時，JMS 會清除自己的 Discord 播放狀態。帳號切換不會沿用另一個帳號的同意。Discord 未啟動或連線失敗時，不影響 JMS 播放，也不需要輸入 Discord 密碼或 Token。

此整合使用公開 Application ID `1555974444369969292`。播放狀態不包含服務網址、媒體連結、帳號、密碼、Cookie 或 Token。若您同意分享影片名稱，該名稱會成為 Discord 顯示資訊；請先確認其內容適合公開。

請參閱 [Discord Rich Presence 官方說明](https://docs.discord.com/developers/platform/rich-presence)及 [Discord 活動分享設定說明](https://support.discord.com/hc/en-us/articles/7931156448919-Activity-Sharing-on-Discord-FAQ)。
