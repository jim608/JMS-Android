# JMS 0.11.1-jms.33

## 新增
- Android、Windows 與 Linux 的環境光新增自訂更新間隔，支援毫秒精度，預設維持 4 秒。
- 環境光新增跟隨畫面更新模式，可依偏好調整取樣間隔。快速更新時顯示效能、耗電與發熱提示。

## 修正
- 修正 Windows 與 Linux 啟用 Discord 狀態分享後仍顯示未連線的問題。
- 修正 Discord 分享未即時跟隨全域隱身模式設定的問題；保留帳號、伺服器及片名分享同意的隔離。

## 已知問題
- Discord 狀態僅支援 Windows 與 Linux 桌面版，Android 與一般 Web 瀏覽器尚未提供。
- Linux 支援範圍為 EndeavourOS／Arch x86_64，套件尚未刊登 AUR，未提供 Flatpak。
- Windows 內建播放器目前採用相容影像輸出，畫面輸出上限為 1920×1080；硬體解碼可維持啟用。

## 更新注意事項
- 本版為測試版，接收新版須啟用「接收測試版」；下載完成後仍由使用者確認安裝。
- 環境光實際更新速度受裝置畫面刷新率及取樣耗時影響。高頻取樣可能降低播放流暢度，建議依裝置效能調整。
- Discord 桌面版須在同一台電腦開啟並登入；播放狀態與片名分享仍須分別啟用，並受 Discord 活動隱私設定影響。
- Android ARM64 沿用既有測試簽章；Windows 與 Linux 未提供正式發行者簽章。保留帳號與下載設定，請勿解除安裝或清除資料。
