# JMS 0.11.1-jms.34

## 修正
- 修正 Android 更新器初始化失敗後無法再次檢查更新的問題，並區分設定、裝置資訊及更新服務的失敗原因。
- 修正舊下載記錄無法還原時，更新開關與檢查按鈕持續停用的問題。
- 修正安裝取消或遭阻擋後殘留的待確認狀態，重試時仍會重新驗證安裝包。

## 已知問題
- Android 尚未提供 Discord 播放狀態。

## 更新注意事項
- 本版為 Android ARM64 測試版，沿用既有測試簽章，安裝仍須由使用者確認。
- 若舊版無法點選「檢查更新」，請從本版 Release 下載 APK 覆蓋安裝，勿解除安裝或清除資料。
- 簽章、SHA-256、平台或版本不符時仍拒絕安裝，不會以重試略過驗證。
