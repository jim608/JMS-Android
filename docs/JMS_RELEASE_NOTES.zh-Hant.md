# JMS 0.11.1-jms.26

## 修正
- 修正 Android 切換視窗或離開更新頁時取消 APK 下載的問題；使用者確認下載後，以背景工作繼續傳輸。
- 支援同一更新版本的部分下載續傳及有限次網路重試，回到 App 後恢復下載狀態。
- 保留來源、平台、版本、檔案大小、SHA256 與簽章核對；背景完成下載後不自動安裝。

## 已知問題
- 本版切換視窗、背景下載、系統中斷後續傳與覆蓋升級仍待手機實測。

## 更新注意事項
- 本次提供 Android ARM64 測試版，沿用既有測試簽章；須啟用接收測試版。
- 更新下載會顯示背景工作通知，可由使用者取消；安裝仍須回到 App 確認。
- 不需解除安裝或清除資料；既有服務與帳號設定保留。
