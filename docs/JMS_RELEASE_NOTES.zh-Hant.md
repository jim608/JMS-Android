# JMS 0.11.1-jms.25

## 新增
- 新增匿名錯誤與慢幀回報，可在「設定 → 關於」設定接收端並明確同意後啟用；預設關閉。
- 回報僅包含平台、版本、建置識別、錯誤分類與彙總幀時間，不傳送錯誤全文、帳號、服務網址、密碼、Cookie 或 Token。

## 修正
- 修正尚未登入時的路由處理，讓首次啟動能正確顯示登入頁。
- 補齊 EndeavourOS／Arch Linux 套件的 NetworkManager 執行相依。

## 已知問題
- 匿名回報涵蓋 Flutter 錯誤與慢幀，尚不涵蓋原生崩潰、GPU 或音訊裝置診斷。
- 手機覆蓋升級、EndeavourOS／Arch Linux 實機播放與完整桌面更新仍需裝置驗證。

## 更新注意事項
- 診斷接收端必須使用 HTTPS；未設定接收端或未同意時不傳送資料。可隨時關閉回報。
- Android ARM64 沿用既有測試簽章；Windows 安裝程式與 Linux 套件未提供正式發行者簽章。
- 接收測試版須於設定中啟用；自動檢查更新不會自動安裝。Web 由管理者部署更新。
- 保留既有服務與帳號設定，不需解除安裝或清除資料。
