# JMS 0.11.1-jms.14

## 調整
- 調整既有 Jellyfin 登入使用者的點片連動：若部署服務未明確提供快速連線能力，改用 JMS 原生視窗進行一次 Jellyfin 密碼驗證，不再單憑版本號嘗試快速連線。
- 改善點片服務的連線診斷，分別顯示快速連線、Jellyfin 驗證、Cookie 處理與本人身分核對結果，不包含登入憑證。

## 修正
- 修正 Jellyseerr 快速連線遭拒絕後未進入 Jellyfin 密碼重新驗證流程的問題。
- 修正 Jellyseerr Cookie 在本人身分確認前即可能寫入長期儲存的問題；拒絕回應中的 Cookie 不再被視為有效登入工作階段。
- 修正快速連線遭拒絕時可能誤顯示為帳號權限不足的提示。

## 已知問題
- 既有僅保有 Jellyfin 登入權杖的使用者，如無有效點片工作階段且快速連線不可用，須於 JMS 輸入一次 Jellyfin 密碼。手機上的本人登入與重新啟動後恢復仍待實際確認。

## 更新注意事項
- 此版本維持測試版；安裝後請確認點片服務連接狀態與重開 App 後的工作階段恢復。Jellyfin 媒體庫登入不需清除或重設。
