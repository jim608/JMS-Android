# JMS 0.11.1-jms.30

## 新增
- EndeavourOS／Arch Linux x86_64 提供固定版本與 SHA256 的本機 `yay -Bi`／`makepkg` 套件配方，並保留官方 pacman 安裝套件。

## 調整
- 更新頁依下載階段顯示單一主要操作，版本說明可展開查看；同一版本重新檢查或短暫網路故障時，保留已校驗的安裝包。
- Linux 更新器辨識官方與本機配方套件，社群套件須由使用者手動更新，不會靜默移除或切換安裝渠道。

## 修正
- Seerr 完成本人身分確認後收起連線提示；工作階段失效時重新顯示，並保留帳號與服務來源隔離。
- 修正桌面最大化與還原圖示，視窗狀態改變後會即時更新。
- Windows 保留硬體解碼並使用相容的畫面傳送路徑，修正硬體加速時可能只有聲音而畫面全黑的問題。
- 等待播放器初始化完成才載入影片，初始化失敗會清除未就緒資源並顯示既有錯誤提示。
- 將可安裝狀態綁定完整版本、平台、來源與校驗資料，拒絕未驗證安裝包及失效的安裝確認。
- Web 容器支援唯讀掛載網站入口設定；設定不存在時回傳 JSON 404，保留首頁、子路徑與原本的 Web 設定。

## 已知問題
- 本機 Linux 配方尚未刊登 AUR，不能使用 `yay -S jms-bin`。
- Windows 相容顯示路徑目前最高輸出 1920×1080；更高解析度影片會縮小顯示。長時間播放與不同顯示卡仍待驗證。
- 手機覆蓋升級與播放、EndeavourOS／Arch 實體桌面的播放及互動式授權，仍待裝置驗證。

## 更新注意事項
- 本版為測試版，須啟用接收測試版；下載完成後仍須由使用者確認安裝。
- Android ARM64 沿用既有測試簽章及應用程式識別。Windows 與 Linux 未提供正式發行者簽章。
- 保留既有帳號、服務與下載設定，不需解除安裝或清除資料。診斷回報仍須另行同意。
- Windows、Linux、Android 使用各自的更新來源；Web 由管理者更新網站部署。
