# JMS 0.11.1-jms.41

## 新增
- Windows 的 Discord 播放狀態支援分享作品封面，動漫單集使用整部作品的海報。
- 新增獨立的「分享作品封面」開關，須先同意播放狀態與影片名稱分享。

## 已知問題
- 封面需要 Jellyfin 提供可用的 TMDB 或 TVDB 公開海報；沒有可用圖片時維持文字狀態。
- Windows App 與安裝程式尚未提供正式發行者簽章。

## 更新注意事項
- 本次提供 Windows x64 測試版；更新前請退出 JMS，覆蓋安裝並保留既有帳號與設定，勿解除安裝或清除資料。
- 作品封面分享預設關閉，啟用後會將公開封面網址傳送至 Discord；不分享私人伺服器圖片網址或認證資料。
