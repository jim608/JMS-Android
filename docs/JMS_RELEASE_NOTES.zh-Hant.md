# JMS 0.11.1-jms.17

## 新增
- 新增 Windows 桌面版線上更新功能，可於「設定 → 關於」檢查、下載並確認安裝更新；自動檢查不會自動安裝。

## 調整
- 將播放診斷入口整合至播放器的三點選單，未開啟診斷時不顯示浮動按鈕。
- Windows 播放使用 MPV，原有 MDK 偏好保留，但不再提供 MDK 後端。

## 修正
- 修正播放器黑色背景遮住環境光的問題，依實際影片顯示區域將光暈繪製於上下或左右留白，並在長寬比改變時保護主影片區域。
- 修正未開啟播放診斷便離開播放器時，嘗試移除未註冊畫格回呼的問題。

## 移除
- 移除 Web 的 App 更新控制與更新通知；Web 版本由伺服器部署更新。

## 已知問題
- Windows 測試安裝程式未經程式碼簽章，系統可能顯示安全提示。
- 環境光依播放器的顯示矩形辨識留白；影片檔內編碼的黑色畫面不會被裁切或當成背景覆蓋。Web 不提供原生環境光。
- 各平台實際播放、字幕特效及更新後設定保留仍需裝置驗證。

## 更新注意事項
- Windows 舊版本需先安裝包含線上更新功能的版本，之後才能從 App 接收更新。測試版本須開啟「接收測試版」。
- 保留使用者已儲存的伺服器與更新偏好；新安裝需自行設定服務來源。
