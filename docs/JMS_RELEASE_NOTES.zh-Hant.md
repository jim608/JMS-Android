# JMS 0.11.1-jms.28

## 修正
- 修正 Android 電影與影集離線下載在拒絕通知權限時，未啟動前景下載服務的問題。
- 未知檔案總長度的下載也會在傳輸開始前啟動前景服務，避免切換視窗後失去背景下載保障。
- 保留既有暫停、取消、續傳、有限次重試及僅 Wi-Fi 設定。

## 已知問題
- 手機切換視窗、拒絕通知權限、未知長度下載、系統中斷後恢復與覆蓋升級仍待實機驗證。

## 更新注意事項
- 本次提供 Android ARM64 測試版，沿用既有測試簽章；須啟用接收測試版。
- 此修正針對電影與影集離線下載；保留上一版 APK 線上更新的背景下載修正。
- 不需解除安裝或清除資料；既有服務、帳號與下載設定保留。
