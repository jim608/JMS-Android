# JMS 0.11.1-jms.22

## 調整
- Windows 原生播放與圖形元件改用可追溯的套件及固定來源修訂，保留各元件授權與對應材料。

## 修正
- 尚未設定 Seerr 服務時，點選登入會開啟服務網址設定，不再沒有回應。
- 修正首次儲存 Seerr 網址被誤判為帳號切換而取消的問題；儲存後仍須確認 Jellyfin 帳號連結。

## 已知問題
- EndeavourOS／Arch Linux 的 GPU 播放、字幕效果及完整桌面升級仍需實機驗證。
- Windows 安裝程式與 Linux 套件未提供正式發行者簽章；Android 使用既有測試簽章。

## 更新注意事項
- Linux 需可解鎖的 Secret Service 金鑰圈及 PolicyKit 桌面代理；金鑰圈不可用時不使用明文儲存登入憑證。
- 測試版需啟用測試渠道；自動檢查更新不會自動安裝。Web 由管理者部署更新。
- 服務網址透過使用者設定或部署配置提供，不包含私人服務預設值。
