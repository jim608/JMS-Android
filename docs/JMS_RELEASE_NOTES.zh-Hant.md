# JMS 0.11.1-jms.29

## 新增
- Android 可在原本的伺服器欄位輸入 JMS 網站入口，自動讀取 Jellyfin、Seerr 與選用診斷接收端設定；保留直接連線 Jellyfin 的用法。
- 新增按伺服器保存的有效入口設定，以及設定頁的來源查看與手動重新讀取功能。

## 調整
- 手動服務設定保留優先權。入口暫時故障時沿用上次有效設定，服務來源變更後須確認並重新登入或連動。
- 診斷接收端按伺服器與帳號隔離，接收端或帳號變更會撤銷原有上傳同意；入口設定不能自行開啟診斷回報。

## 修正
- 固定登入與伺服器資訊查詢的請求來源，避免連線期間切換伺服器造成憑證混用。
- 將入口快取與診斷接收端排除於設定備份及匯出，並避免未設定 Seerr 的入口套用其他來源。

## 已知問題
- 網站管理者須另行部署 HTTPS 設定入口；App 更新不會自動修改網站。正式網站整合與手機操作尚待實際驗證。

## 更新注意事項
- 本版為 Android ARM64 測試版，沿用既有測試簽章與應用程式識別，可覆蓋安裝並保留資料；不代表正式簽章。
- App 不內建私人服務網址。入口探索採未登入 HTTPS 請求，設定取得後仍須由使用者在裝置上同意診斷上傳。
