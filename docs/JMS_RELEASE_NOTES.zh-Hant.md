# JMS 0.11.1-jms.10 原生點片／回報／帳號連動本機測試版

- 以既有 Seerr client 整合原生「點片」搜尋、電影／選季申請、「我的紀錄」申請與回報分頁、留言及依權限處理解決狀態。媒體詳情與播放選單可預覽並回報問題，不上傳影像、原始 log 或播放 URL。
- 加入明確的 Jellyfin ↔ Seerr 來源確認、本人 jellyfinUserId 核對、單一背景登入任務與 Android Keystore 加密工作階段。新登入可在告知及確認同一服務後使用該次帳密一次連接；既有使用者先還原 Cookie，能力允許時使用 Quick Connect，否則原生最小重新驗證。不保存密碼、不以管理員代點。
- 已確認的來源為 https://legacy-seerr.example.invalid，但其保護拒絕本機公開 API 查詢；依使用者要求改用隔離 fixture 測試，不繞過保護、不再反覆探測。部署版本、實際帳號政策、Quick Connect 與端到端送出尚未驗證。
- 修正 Chopper 回應轉 ApiResult 時誤讀同名 Body 註解常數造成成功資料遺失；修正 Seerr 子路徑、帳號隔離、舊搜尋回應覆蓋、配額／權限及重複提交保護。POST 結果不明時先查紀錄，不盲目重送。
- App 原生畫面使用合成資料完成本機操作及深／淺色、文字放大截圖；不是手機或正式服務驗收。Android 加密儲存與覆蓋安裝仍須手機確認，其他平台此新增工作階段暫只保留於記憶體。
- 環境光與播放渲染、ASS、睡眠計時、設定備份與更新協定不變。遙測／Laya 未啟用且不是點片前置條件。既有 ASS 待驗狀態不變。
- 本輪依最新工作區「不發布」及「先本機測試」指示交付本機 APK，未推送／上傳／建立 Release；既有發布入口仍保留，日後符合授權及 gates 時沿用。不要把本說明當作已上線。

## 保留的 .9 發布紀錄

- 依使用者同意，Android 完整排除 MDK/fvp 原生 SDK，保留既有 MPV 與 Native。MPV 函式庫及環境光取樣／強度／擴散／合成不變。
- 若曾指定 MDK，Android 改用 MPV，設定頁會說明；原 MDK 偏好值保留、不清除登入或其他設定。其他平台的後端宣告不變，本版僅驗收 Android 產物。
- 修正重複 `libass.so` 的打包來源：Native 使用原鎖定 ass-kt 0.3.0 AAR 的 libass 0.17.4，移除 MDK libass 0.17.5 與 pickFirst 隱藏衝突。檢查完整字幕符號 ABI，MPV 內嵌 libass 不變；這不代表使用者原 ASS 特效問題已通過實機驗收。
- 加入原生第三方完整授權聲明與精確來源／建置材料；App 關於頁開源授權可查，Release 另附相應來源封存。公開 Prerelease 的手機播放、字幕、覆蓋升級與設定保留仍由使用者確認。

- 本版用於首次 `.8 (2008)` → `.9 (2009)` 同簽章線上更新驗證；發布頻道為 Prerelease，需在 `.8` 的設定 → 關於 → JMS Android 線上更新開啟「接收測試版」。
- 串接本機檢查、來源快照 commit/tag、建置、簽章及授權核對、完整草稿上傳、發布與匿名下載驗證。普通建置／存檔不會自動發布。
- 發布工具保存階段狀態，中斷後接續，不覆寫已發布 APK／版本；來源、update.json、校驗與必要原生材料均須一致才公開。
- 將不適用的 Counter 樣板測試改為真實 JMS 未登入啟動測試，驗證正確進入伺服器登入畫面而非虛構計數器。
- 除本次版本標識，不改動 `.8` 的環境光、播放器、字幕渲染、睡眠計時、設定備份、登入資料與更新格式；沒有虛構新播放功能。
- ASS 特效仍待獨立手機驗收；環境光保留既有人工通過狀態，未新增量化效能宣稱。手機覆蓋升級／設定保留由使用者實測，不等同發布或匿名下載成功。
- 沿用 com.jim608.jms 及 `.8` 相容簽章；不卸載、不清資料、不要求 GitHub 登入。來源及簽章稽核未通過時發布工具停止，這份待發布說明不表示已經公開。

## 保留的 .8 功能

- 新增播放選單 →「睡眠計時」：1–720 分鐘倒數、剩餘時間、修改、取消，以及「播完本集停止」。以截止時間及真正完成事件控制，不改寫觀看完成狀態。
- 倒數包含暫停、背景及手動換集；本集停止在手動換集時取消。結束播放／程序重啟清除計時；系統暫停或終止程序時不保證準時執行，恢復時核對截止時間。到期後按播放可解除暫停。
- 新增設定 → 用戶端 →「設定備份與還原」：匯出 20 項非敏感偏好，還原先預覽再確認；不包含帳密、伺服器、觀看紀錄、更新來源或簽章信任設定。播放期間不可還原。
- 備份支援 schema、64 KiB 大小及欄位／數值驗證；完整驗證後以單一設定值提交，失敗嘗試完整回復並明示錯誤。保留帳號與其他本機設定，舊設定 key 不刪除。
- 修復浮動搜尋舊回應覆蓋新查詢、清空後結果回流、重複請求及錯誤 loading；補取消清理與重試。
- 修復播放器重建的訂閱留存，將初始化序列化，避免同時多次初始化。不更換播放器；未宣稱實機 frame time、耗電或記憶體效能改善。
- 環境光取樣／強度／擴散／合成、ASS 渲染及 GitHub 更新來源 jim608/JMS-Android 保持不變。ASS 原問題仍待手機特效驗收；環境光原有人工通過不等於本輪量化測量。
- 沿用 com.jim608.jms 與既有測試簽章。只供人工覆蓋安裝測試，不卸載、不清資料；手機安裝／背景／資料保留與真正線上升級仍待驗。
- `.8` 原 Counter smoke failure 的處理與本輪驗證結果見 JMS_STATUS.md M12。發布授權不取代金鑰保管及原生授權／來源檢查。
