# Steam Deck 安裝設計草稿

**目前沒有本輪專用安裝產物或已確認的 Steam Deck 安裝格式。** 此文件不提供系統修改或安裝命令，也不要求朋友提供裝置或登入。

## 先辨認執行環境

| 情況 | 目前可確認的來源界線 | 尚待確認 |
| --- | --- | --- |
| Steam Deck 上的 Android 執行環境 | 共用 Flutter Android 工程與既有 Android 產物／更新路徑 | Android 環境、ABI、手把事件、視窗縮放與現有 APK 相容性 |
| SteamOS／Linux 執行環境 | 共用 Flutter Linux 工程；現有 `JMS-Linux` 發行契約 | SteamOS 安裝包裝、依賴、圖形／音效、輸入與更新方式 |

既有 Android 更新程式只接受其已定義的平台／ABI；不得因裝置名稱相同，假定現有 APK 可在任意 Android 環境安裝。既有 Linux 更新則驗證 Arch 套件與 `.PKGINFO`，不應將該驗證直接當作 SteamOS 安裝驗收。

## 發行前應備妥

- 選定包裝與安裝位置，記錄相應原生依賴與授權材料。
- 產物綁定共用來源 commit、版本、Build ID、大小與 SHA-256；使用者看到的安裝說明與產物一致。
- 在相應目標環境驗證首次啟動、既有設定保留、更新／取消與回復路徑。
- 將 Android 與 Linux 的安裝文件及結果分開，避免跨平台導向。

本輪只做本機共用 UI／輸入開發，不安裝或覆蓋使用者現用 App，不改動系統、安全、網路或帳戶設定。Flatpak 未確認納入本輪，不因已有歷史檔案而視為選定方案。
