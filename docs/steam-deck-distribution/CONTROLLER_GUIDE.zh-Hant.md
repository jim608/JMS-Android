# 手把操作指引草稿

這是本輪共用 UI 實作的操作與裝置驗收草稿；本機自動化與隔離 Windows 操作結果已記錄，實體 Steam Deck／Android／SteamOS 仍待驗。以下以功能描述操作，實際按鍵與映射以本輪共用 UI 實作為準；本輪預設不代表使用者指定不可更改的按鍵。

## 操作原則

- 方向輸入在可操作元件間移動可見焦點；使用者應能預測同列、下一列與側邊導覽的移動結果。
- 確認只觸發目前焦點的主要動作一次。按住、重複事件及放開不得造成重複開頁或重複播放。
- 返回依目前層級關閉選單／對話框、返回上一頁，並恢復先前可用的焦點。頁面或項目已移除時，落在仍可操作的合理位置。
- 手把模式保留清晰的焦點提示與足夠的點擊區域。滑鼠、鍵盤與觸控仍可使用，切換輸入方式不得讓操作失效。
- 捲動與焦點一起移動，選中的元件應保持可見，不以搖桿模擬滑鼠游標作為主要導覽。

## 播放中

控制列、字幕／音軌選單、播放選項與對話框都應能以方向、確認、返回完成操作。隱藏的控制列不應仍攔截焦點；操作控制列或選單時，焦點不得因自動隱藏計時器而消失。

播放器原有鍵盤快捷鍵、觸控手勢、字幕與 SyncPlay 行為需分別回歸。手把方向焦點導航不得意外同時觸發音量或跳轉。

## 實機待驗

需記錄朋友實際使用的 Android 執行環境／版本、JMS 版本、控制器事件與可用映射，並分開記錄 SteamOS／Linux 結果。沒有實體 Steam Deck 時，合成按鍵／視窗尺寸測試只證明相應軟體路徑，不代表內建搖桿與系統映射已通過。

完整逐項記錄見 [驗收清單](ACCEPTANCE.zh-Hant.md)。

## 本輪實作預設

Android 主 Activity 的左搖桿／方向帽使用方向焦點，A 為確認、B 為返回。Linux Steam Input 若只輸出鍵盤事件，明確以 `--handheld` 啟動，再將方向映射箭頭、確認映射 Enter、返回映射 Escape；本輪沒有代改 Steam 設定。普通鍵盤模式保留原播放器音量／快轉快捷鍵。

返回順序為先關對話框或目前浮層、再隱藏控制列、最後退出播放器；可用的原控制項會恢復焦點。確認需配對按下與放開，避免關閉對話框後又觸發底層。

此增量針對預設 MPV 的 Flutter 控制 UI；獨立 Native／Android TV 的 Compose 播放 UI 未重寫。Linux 直接讀原生類比軸尚未實作。
